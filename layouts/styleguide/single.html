Out of date below The direction the next paragraphs describe is massa, and the shipped palette is no longer massa. The layout, the type and the rules still hold; the colour sentences do not. Read the swatches rather than the words until the direction is rewritten.

Seventy percent of a construction project is material. That is the number the whole business rests on, so the page is built to carry the weight rather than to decorate it.

  • The headline is the loudest object on the page. Display type is set very large and very wide, edge to edge, with almost no chrome around it. Nothing else needs to shout, because that already does.
  • Grounds are sampled from the site, not from software. Bitumen, zinc, concrete, chalk. No blue, no gradient, no photograph of a hard hat.
  • One accent, menie, and it is allowed to mean something. The red lead primer that goes on Dutch steel before anything else. If a component wants colour, the answer is a hairline or a change of ground.

Sections are bands, cut by a hairline. There are no cards on grey, no shadows and no rounded panels anywhere in the system.

What this replaced Two earlier attempts: a generic SaaS pattern, then a tender document pattern in warm paper with a serif and a ledger rail. The second read as competent, and landed on a well worn look rather than a chosen one.

02b Roles

Nothing reads a colour by name.

main.css, section 01b

The swatches above are the palette: colours with names. Between them and the components sits a second layer, roles: what a colour is for. A component only ever reads a role.

The point is what it removes. A band that changes its ground restates the roles once, and every component inside it follows, including components written afterwards. Before this layer the stylesheet carried about forty rules of the shape .band--chalk .thing { color: ... }, one per component per ground, and the tint band was missing a third of them, which is why an eyebrow on it sat at 2.6:1.

The accent needs three roles rather than one because no single accent value clears contrast on both grounds. Small text steps per ground; display type and fills do not. That split is what lets an accent as bright as this one be used at all.

What a palette is now A palette file redeclares the named colours and stops. No component rules, no per band overrides. If a palette ever needs one, the role layer is missing a role, and that is the thing to fix rather than the palette.

{{/* 09 MOTION, ACCESS, BUILD --------------------------------------------- */}}

09 The rest

Motion, access, build.

DESIGN.md, closing sections

Motion

Bands rise 10px and fade in on first view, staggered by 60ms. Nothing else moves: no parallax, no scroll jacking, no carousel. All of it is disabled under prefers-reduced-motion, and the reveal class is added by script, so with JavaScript off nothing is ever hidden.

Accessibility

  • AA contrast on every text pairing, verified per token pair rather than per component.
  • Focus rings are menie-lt at 2px with 3px offset, visible on both grounds. Tab through this page to see it.
  • Body copy 17px minimum, 1.62 line height.
  • Fonts self hosted, font-display swap, subset to the three languages.

Budget

One stylesheet, one 2 kB site script, one 3 kB scan script. No framework. This page is the one exception: it loads a second stylesheet of its own so the site bundle does not carry it.

Build

Hugo 0.147.3 extended or newer, the version CI uses. On 0.139 the section templates are not picked up and inner pages render empty, which is easy to miss because the pages still return 200.

Known issue The chat widget embeds an OpenRouter API key in client side JavaScript, where any visitor can read it, and posts visitor messages to a service outside the EU. Both sit badly next to the data sovereignty argument the site makes. Both are flagged in the privacy policy; neither is fixed.
