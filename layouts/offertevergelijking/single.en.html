UC1: Bid comparison

From five bids to an audit-ready comparison report. In minutes.

Construction procurement teams spend an average of thirty minutes comparing six bids: for every tender, every week. Dundir replaces that manual work with a deterministic calculation process that produces the same result for the same input, every time.

The problem

A procurement manager receives five bids for the same work. Each bid has a different structure, different line item groupings, different assumptions about materials and labour. To compare them fairly, he has to normalise them manually: calculate unit prices, identify omissions, line up delivery timelines.

That takes thirty minutes. And no report has been written yet. Scale this across the average procurement team and you lose hours every week to work that adds no decision value.

Generative AI does not fix this. In an internal Skanska experiment, a generic enterprise AI system produced different numerical outputs for identical bid inputs: errors up to €8,354 on a single tender line. The system generated answers. It could not reproduce the calculation.

€8,354

maximum calculation error from a generic GenAI system in bid comparison

For identical inputs, the system produced different numerical outputs across separate sessions (up to a 28% discrepancy on a single line item). This is why a generative AI system is not suitable for numerical bid comparison. Dundir's optimisation engine is deterministic: the same result for the same input, every time.

Hamppi 2025, p. 62: Aalto University / Skanska Talonrakennus Oy.

How Dundir handles bid comparison

  1. Bids are normalised

    The AI layer converts heterogeneous bid documents (PDF, email, spreadsheet) into a structured comparison format. Unit prices, delivery times, certification status, assumptions: everything on one line.

  2. The optimisation engine calculates

    Based on your hard requirements (certifications, delivery windows, budget ceiling) and weighted objectives (price, reliability, sustainability), the engine calculates the provably optimal supplier combination. Deterministic: the same result for the same input, every time.

  3. You review. The system documents.

    You see a ranked comparison with source data, certification status, and full reasoning trail. You decide. The system records your decision: ready for internal approval, external audit, or public procurement review.

What it delivers

Time saved
30 minutes of manual work per comparison, scalable across any procurement volume without additional headcount.

Reproducibility
The same input always produces the same result. No variation between sessions, buyers, or moments in time.

Audit-ready report
Every comparison automatically produces documentation suitable for internal approval, external audit, or public procurement review.

Knowledge retention
When a senior procurement officer leaves, the calibrated decision logic stays available to the whole team.
